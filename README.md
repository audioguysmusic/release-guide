# AUDIOGUY 음원 발매 가이드

정적 HTML 사이트입니다. `index.html`과 같은 폴더에 있는 모든 파일을 GitHub 저장소 루트에 업로드하고 Settings → Pages에서 배포할 브랜치와 `/ (root)`를 선택하세요. 별도의 빌드는 필요하지 않습니다.

장르와 크레딧 검색 데이터는 각각 `genres.js`, `contributors.js`에 있습니다. 문서 본문은 `data.js`, 화면 동작은 `app.js`, 스타일은 `style.css`에서 관리합니다. Bulma, Phosphor, 웹폰트는 외부 CDN을 사용하므로 인터넷 연결이 필요합니다.

공개 전 모바일과 데스크톱에서 내용을 확인해 주세요. GitHub Pages는 공개 사이트이며 링크를 받은 사람만으로 접근이 제한되지 않습니다.
